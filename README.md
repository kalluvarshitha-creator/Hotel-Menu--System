# Hotel-Menu--System
📌 Project Description

The Hotel Menu System is a simple console-based Java application that allows customers to select food and beverages from a hotel menu, calculate their total bill, and make payments using different payment methods.

This project is developed using basic Java programming concepts such as loops, switch statements, methods, and user input handling.

✨ Features
Main Menu: Displays the available options.
Breakfast Menu: Offers different breakfast items.
Tea & Coffee Menu: Allows customers to select beverages.
Add Items: Customers can select multiple items.
Bill Calculation: Automatically calculates the total amount.
Payment Options: Supports three payment methods:
Cash
UPI
Card
Payment Confirmation: Displays a successful payment message.
Exit Option: Allows customers to exit the application.

bash

Step 2: Open the project in any Java IDE (Eclipse, IntelliJ IDEA, or VS Code).

bash
